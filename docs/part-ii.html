E8Determinism (R4)

The same probe was scored inside 5 batch compositions whose recorded sizes range from 37 to 2,037 events. Every composition produced the byte-identical verdict digest 4e576f78c540… (identical = true), and 64 repeated runs of the same batch reproduced it (stable = true).

The negative control is a detector standardising against the batch per equation (1); its scores MUST differ across these compositions, or the check has no power.
